# Trinicorn SLM Toolhead

Trinicorn is a high-performance, open-source Selective Laser Melting (SLM) toolhead designed for advanced CoreXY 3D printers (such as the Voron Trident). It combines rigid mechanical engineering, optimized thermals for high-flow printing, and seamless Klipper integration.

## Key Features
* **SLM Optimized Design:** Engineered for maximum thermal efficiency and precise material extrusion.
* **CoreXY Compatible:** Designed with lightweight rigidity in mind, perfect for high-speed, high-acceleration motion systems.
* **Klipper Ready:** Includes native configuration macros and optimized thermals right out of the box.
